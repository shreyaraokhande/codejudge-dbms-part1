# CodeJudge DBMS Schema Design

## Overview

This repository contains the database schema design and normalization analysis for the CodeJudge platform dataset.

The project focuses on:

- relational schema design
- primary and foreign keys
- normalization
- integrity constraints
- entity relationships
- ERD creation
- database assumptions

---

# Repository Contents

| File | Description |
|---|---|
| schema.sql | SQL table creation scripts |
| schema_explanation.md | Explanation of database schema |
| keys_and_relationships.md | Keys, constraints, and relationships |
| normalization_notes.md | 1NF, 2NF, and 3NF analysis |
| assumptions.md | Design assumptions |
| erd.md | Entity Relationship Diagram description |

---

# Database Features

- normalized relational design
- one-to-many and many-to-many relationships
- composite keys
- foreign key constraints
- unique and check constraints
- scalable schema structure
